feat: seamless zero-amount payment bypass for 100% off promo codes

Problem Statement:
1. When a 100% off promo code was applied, the checkout flow would initiate a Razorpay transaction for ₹0.
2. Razorpay mathematically blocks any transaction where the amount is strictly ₹0 (minimum ₹1.00), causing the checkout to crash.
3. We needed a frictionless UI/UX for users applying these free promo codes, avoiding unnecessary payment gateway interactions.

Fixes Implemented:
1. Backend Order Fulfillment: Intercepted `finalAmountPaise === 0` in `/api/payments/create-order`. It now auto-generates a `free-...` order document and immediately triggers `applyPlanUpgrade` using a `promo_free` source, seamlessly consuming the promo code server-side without contacting Razorpay.
2. Frontend Bypass: Added a `freeFulfillment` flag in the API response which the client intercepts to skip `loadRazorpayOptions`.
3. Premium Free-Tier UI: Introduced a new `free_success` state in the payment overlay featuring dynamic Framer Motion animations (PartyPopper & Sparkles), a glassmorphic success card, and a clear "₹0.00 Charged" breakdown, followed by an automatic 5-second redirect.
